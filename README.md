# Практикум по Python

Практикум из 45 задач для начинающих. У каждой задачи своё поле для кода и автоматическая проверка. Черновики и принятые решения сохраняются в браузере. Принятые решения можно скачать одним текстовым файлом.

Откройте [dist/index.html](dist/index.html) в браузере. При первом запуске проверки нужен интернет для загрузки Python. В практикуме разрешены команды из курса. Проверка ограничивает вычисления и выполняется в браузере.

Папка [materials](materials) содержит презентацию первого занятия, условия задач и отдельные документы с решениями для преподавателя. Исходные данные с эталонными решениями находятся в [data/exercises.json](data/exercises.json).

Для сборки и проверки из корня проекта используйте Python 3.10 или новее.

```sh
python build.py
python -m unittest test_sandbox
```

Команда сборки проверяет 45 эталонных решений и создаёт `dist/index.html`. Для локального превью можно запустить `python -m http.server --directory dist 8000` и открыть `http://localhost:8000/`.
